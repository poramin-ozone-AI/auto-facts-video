AUTO FACTS VIDEO v4.1 — บันทึกการปรับปรุง

ฐานพัฒนา: auto-facts-video v4.0 (ZIP ที่ผู้ใช้อัปโหลดใน Library)
สถานะ: แก้ไขใน workspace และตรวจแบบ offline แล้วเท่านั้น ยังไม่ Commit/Push, ไม่รัน GitHub Actions และไม่เรียก Gemini/Cloudflare/Pollinations API จริง

การเปลี่ยนแปลง
1) วิดีโอเป้าหมาย 1080x1920, 30 FPS, H.264/AAC; ภาพต้นทางยังสร้าง 720x1280 แล้ว upscale ใน FFmpeg เพื่อไม่เพิ่มขนาดคำขอภาพ/โควตา API
2) คง zoom เส้นตรง 1.00→1.05; ลด intermediate upscale จาก 4x เป็น 2x เพื่อลด RAM/ภาระ CPU ระหว่างเรนเดอร์ 1080p
3) ซับ: ใช้ faster-whisper tiny CPU int8 เพื่อดึง timestamp ระดับคำเมื่อโมเดลส่งมาได้ และใช้ระดับ segment เป็น fallback และคงข้อความ narration ต้นฉบับ; หาก Whisper ใช้ไม่ได้ให้ fallback เป็น timing แบบสัดส่วนเดิม
4) เสียง: ลด silence tail จาก 0.4 เป็น 0.2 วินาที/ฉาก; normalize หลังรวมคลิปด้วย loudnorm เป้าหมาย -14 LUFS Integrated, True Peak -1 dBTP, LRA 7; ต้องฟังเทียบจริงก่อนล็อกค่า
5) รวมฉาก: ใช้ video stream copy เมื่อพารามิเตอร์ของคลิปฉากตรงกัน แล้วเข้ารหัสเฉพาะเสียงพร้อม loudness normalization เพื่อลดการ encode วิดีโอซ้ำรอบสุดท้าย
6) STYLE ย่อและจัดต้น prompt ให้ Kawaii Chibi / watercolor / full-bleed มาก่อน โดยรักษา character identity lock
7) Script: ค่าเริ่มต้น SCRIPT_MAX_CHARS 900 และ temperature 0.65; เพิ่ม source_hint เป็นแนวทางอ้างอิงใน prompt
8) Image QC: ตรวจการเปิดไฟล์, ขนาด, ความแปรปรวนของภาพ และขอบสว่างคล้ายกรอบ; หากไม่ผ่านจะลองผู้ให้บริการภาพสำรอง แล้วหยุดหากยังไม่ผ่าน
9) Final QC: ตรวจสตรีม, ความละเอียด, codec, ระยะเวลา และรายงาน loudness
10) เพิ่ม dependency faster-whisper และ Pillow; เพิ่ม cache โมเดล Whisper ใน workflow

ข้อจำกัด/ความเสี่ยงที่ยังต้องทดสอบ
- Whisper segment timestamps ไม่ใช่ forced alignment ระดับคำ ความแม่นยำภาษาไทยต้องตรวจจากคลิปตัวอย่างจริง; ระบบ fallback ไป timing เดิมได้
- การ upscale 720p เป็น 1080p ไม่ได้สร้างรายละเอียดแท้เท่าภาพ 1080p native
- 1080p และ Whisper เพิ่มเวลา/หน่วยความจำใน GitHub runner และอาจดาวน์โหลดโมเดล ~tiny ในการรันแรก
- loudnorm ช่วยความดังเฉลี่ย แต่ต้องฟังตรวจเสียงแตก/เสียงอัดแน่นและความเป็นธรรมชาติ; -14 LUFS เป็นเป้าหมายทดลอง ไม่ใช่การรับประกันระดับเสียงเท่าทุกแพลตฟอร์ม
- Image QC เชิงภาพยังตรวจ watermark/ข้อความ/ความตรงกับบท/ความสวยงามไม่ได้อย่างน่าเชื่อถือ ต้องตรวจภาพด้วยคนก่อนโพสต์
